# Cosmetics Retail Data Cleaning and Preparation

## Tools & Technologies Used

- **Microsoft Excel** — Data cleaning, handling missing values, removing duplicates, standardizing text, and formatting dates.
- **Excel Formulas** — Used `PROPER()`, `IF()`, `IFERROR()`, and date-related formulas to clean inconsistent data.
- **VBA (Visual Basic for Applications)** — Automated repetitive data-cleaning tasks, including date conversion and handling invalid values.
- **Git & GitHub** — Version control, repository management, and project documentation.
- **Data Validation** — Checked primary keys, duplicate records, missing values, inconsistent categories, and invalid numerical values.

## Dataset

A cosmetics retail dataset containing product categories, brands, prices, discounts, quantities, sales channels, customer ratings, and order dates.

## Project Objective

To transform a messy, unstructured cosmetics retail dataset into a consistent, analysis-ready dataset while preserving data quality and documenting the cleaning process.

## Key Data Cleaning Tasks

- Identified and handled missing values.
- Detected duplicate and invalid transaction IDs.
- Standardized brand names and product categories.
- Cleaned inconsistent date formats.
- Validated discount percentages, prices, and quantities.
- Prepared the dataset for further analysis and dashboard development.
